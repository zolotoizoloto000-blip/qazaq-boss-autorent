QAZAQ BOSS AUTORENT — PRO V6

Добавлено:
- Финансы: выручка, расходы, чистая прибыль, депозиты.
- Прибыль по каждому автомобилю.
- Учёт расходов и планового ТО.
- Штрафы и задолженности клиента.
- В заказе: депозит, долг, промокод, статус документов, ответственный.
- Тарифы такси: база, цена за км/минуту, минимальный тариф.
- Промокоды: скидка, лимит, срок действия.
- Диспетчерская карта по последним координатам водителей.
- driver.html: мобильный кабинет водителя с заказами, статусом линии, WhatsApp/звонком и отправкой геопозиции.
- API статуса/координат водителя.
- /api/sync защищён авторизацией администратора.

Для production:
- SECRET_KEY, ADMIN_USERNAME, ADMIN_PASSWORD, DATABASE_URL обязательны.
- Нужен HTTPS.
- Для реальной карты подключить 2GIS/Google/Yandex Maps. Сейчас карта показывает координаты во внутреннем диспетчерском интерфейсе.
- SMS и онлайн-оплата требуют внешних API.
- Перед публичным запуском кабинет водителя и его API нужно закрыть отдельной авторизацией.
